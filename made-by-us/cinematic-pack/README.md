# Cinematic skill pack (made with Max, 29 Oct 2026)

18 skills for cinematic, insane-looking, mobile-first web experiences. Each folder: SKILL.md (when, steps, budget, pitfalls) + tested files.

Order of use on a new build:
1. ux-flow-and-ia -> cinematic-direction (brief) -> ui-design-system -> motion-design-principles
2. ai-asset-pipeline -> scroll-scrub-film / alpha-video-cutout / 3d-design-modeling
3. smooth-scroll-gsap + kinetic-3d-type + webgl-shaders-fx + micro-interactions (+ threejs-scenes, interactive-3d-product, audio-reactive-visuals)
4. mobile-perf-budget -> design-critique-loop (repeat) -> showreel-factory

Engines share one clock: put every per-frame function on `gsap.ticker.add(fn)`.
