## cinematic-pack/ (18 skills)
Our own pack for cinematic, insane-looking, mobile-first websites: direction, design system, motion, scroll-scrubbed film, 3D type, WebGL effects, three.js, perf budget, critique loop, showreel. Start with `cinematic-pack/README.md` for the order of use. Used to build the ONE TAKE portfolio.

## Install into Freebuff
Copy any skill folder into `~/.agents/skills/` (global) or `<project>/.agents/skills/`.
